Bienvenidos a mi página web

Esta página fue creada para practicar el uso de HTML5 y CSS. Aquí se aplicarán diferentes estilos, selectores y elementos para crear un diseño organizado y adaptable.

Acerca de esta página

El propósito de esta página es demostrar algunos de los conocimientos adquiridos sobre HTML5 y CSS. La estructura permite organizar la información de forma clara y aplicar diferentes estilos al contenido.

Servicios

Diseño web

Creación de páginas web sencillas, organizadas y fáciles de utilizar.

Estilos con CSS

Aplicación de colores, tamaños, márgenes y otros estilos visuales.

Diseño responsivo

Adaptación de la página para visualizarse en diferentes tamaños de pantalla.
