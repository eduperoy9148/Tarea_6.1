Bienvenidos

Esta página fue creada como práctica para aprender la estructura básica de HTML, sus elementos, atributos y algunas de las nuevas funciones disponibles en HTML5.

¿Qué es HTML?

HTML es el lenguaje utilizado para crear y organizar el contenido de una página web. Por medio de diferentes etiquetas podemos agregar títulos, párrafos, enlaces, imágenes, listas y otros elementos.

Algunos elementos de HTML

  • Encabezados
  • Párrafos
  • Listas
  • Enlaces
  • Imágenes

Para aprender más sobre HTML puedes visitar W3Schools .

HTML5

HTML5 permite crear páginas web con una estructura más organizada y ofrece nuevos elementos para trabajar con contenido multimedia.

Ventajas de HTML5

  1. Permite organizar mejor la estructura de una página.
  2. Incluye soporte para audio y video.
  3. Facilita la creación de páginas modernas.
  4. Es compatible con los navegadores actuales.
